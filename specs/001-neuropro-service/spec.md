# Feature Specification: Сервис интерпретации тестов «Эгоскоп» (NeuroPro)

**Feature branch**: `claude/psych-test-analysis-service-2ovzbs`
**Status**: MVP реализован (см. `tasks.md`)
**Created**: 2026-06-23

## Summary

Веб‑сервис, который превращает выгрузку психофизиологического теста «Эгоскоп»
(Excel) + скриншот таблицы «смысло‑эмоциональной значимости» в брендированный
клиентский отчёт: математическую диаграмму‑паутинку (когнитивные показатели с
наложенной физиологией) и текстовую интерпретацию, сгенерированную нейросетью по
версионируемому промпту. Отчёт отдаётся как PDF (Verdana) или письмом клиенту.

## Why

Сейчас аналитик обрабатывает каждый тест вручную: считает диаграмму, распознаёт
скриншот, прогоняет промпт, верстает PDF. Тестов будет много и разных типов.
Нужен сервис, который автоматизирует рутину, но оставляет данные достоверными
(диаграмма — математикой, без «галлюцинаций» нейросети) и контролируемыми
(версии промптов, выбор модели, ручная проверка).

## User Scenarios

### Основной сценарий (ручной)
1. Аналитик загружает Excel‑выгрузку теста (или вставляет данные текстом).
2. Сервис извлекает метаданные, тип теста и когнитивные баллы; открывает профиль.
3. Сервис просит вставить (Ctrl+V) скриншот таблицы значимости.
4. Скриншот распознаётся (Yandex OCR); физиологические Зна выравниваются по осям.
5. Показывается диаграмма‑паутинка: когниция ⊕ физиология (математика).
6. По типу теста выбирается активный промпт; нейросеть выдаёт интерпретацию.
7. Аналитик скачивает брендированный PDF (Verdana) или шлёт письмо клиенту.

### Авто‑сценарий (папка‑watcher)
1. В отслеживаемую папку появляется новый `.xls`.
2. Сервис автоматически создаёт профиль (статус «ожидает скриншот»).
3. На дашборде профиль ждёт — аналитик добавляет скриншот и продолжает с шага 4.

### Управление промптами
- Промпты редактируются; каждое сохранение — новая версия (история хранится).
- В версии выбирается нейросеть (OpenRouter / Yandex) и оставляется комментарий
  (виден в списке и в карточке).
- Выбирается активная версия для авто‑режима.
- Все интерпретации сохраняются по конкретной версии промпта.
- Интерпретацию можно удалить (с подтверждением).
- Версию промпта можно удалить **только** если по ней нет интерпретаций.

## Functional Requirements

- **FR1 Ingest.** Принять Excel `.xls` (BIFF8 Эгоскопа), `.xlsx`, `.csv`, либо
  вставленный текст. Извлечь ФИО/возраст/пол/дату/методику и когнитивные баллы.
- **FR2 Тип теста.** Определить тест по строке «Методика» (СМУ, ИЖС/LSI,
  Басса-Дарки…) и выбрать соответствующий промпт автоматически.
- **FR3 Watch‑folder.** Автоподхват новых файлов из настраиваемой папки → профиль
  «ожидает скриншот», открывается на дашборде.
- **FR4 Скриншот.** Принять скриншот таблицы значимости через вставку (Ctrl+V)
  или файл. Распознать через Yandex OCR.
- **FR5 Диаграмма (математика).** Построить радар‑паутинку по баллам Excel и
  **наложить** физиологию (Зна) на те же оси. Без нейросетей.
- **FR6 Интерпретация.** Сгенерировать текст по активному промпту выбранной
  нейросетью; сохранить к версии промпта.
- **FR7 Выдача.** Скачать брендированный PDF (Verdana, лого, диаграмма, таблица,
  текст, контакты) или отправить письмом клиенту.
- **FR8 Промпты.** Версионирование, выбор модели на версию, комментарии, активная
  версия, правила удаления (см. сценарий выше).
- **FR9 Настройки.** Провайдер/модель/OCR/SMTP — в `setup.php`, секреты вне кода.
- **FR10 Цифровой аватар клиента.** По результатам тестов определить, КАК подавать
  клиенту материал отчёта: объём, язык, тон, опору, форму подачи и
  чувствительность к прямым формулировкам, плюс ведущие темы профиля («что для
  клиента важно»). Признаки считает код (`www/lib/persona.php`) по уже
  посчитанным величинам — соотношению каналов СМК, разделам отчёта, уровням шкал
  методики, — у каждого есть основание с числами. Аватар:
  - **обновляется постоянно**: считается по всем живым анализам клиента (один
    нормализованный ФИО = один клиент), значение берётся из самого свежего теста,
    рядом хранится, в скольких анализах оно повторилось;
  - **редактируется оператором**: любой признак заменяется вручную, есть заметка
    о подаче; правка переживает пересчёт, пока её не снимут;
  - **показывается после правки физиологии** на странице результата;
  - **в отчёт клиента не попадает** — это внутренняя техническая информация; в
    нейросеть уходят только указания по форме, с запретом их пересказывать.

## Методики

### Реализованы

- **СМУ** — структура мотивации участия (12 шкал).
- **ИЖС / LSI** — индекс жизненного стиля, механизмы психологической защиты.
- **Басса‑Дарки** — виды агрессии (8 шкал, индексы агрессивности и враждебности).

### Рассматриваются к разработке

Список заказчика (#42). Каждая методика подключается тем же путём, что и уже
готовые: разбор выгрузки → максимумы шкал → канонические описания шкал и итоги
методики в `metrics.php` → семейство промптов. Ничего, кроме текста, нейросети
не отдаётся (Конституция, принцип I).

- Пятифакторный личностный опросник («Большая пятёрка»), 75 пар высказываний:
  экстраверсия — интроверсия; привязанность — обособленность; самоконтроль —
  импульсивность; эмоциональная неустойчивость — устойчивость; экспрессивность —
  практичность.
- Характерологический опросник Леонгарда: гипертимный, возбудимый, эмотивный,
  педантичный, тревожный, циклотимный, демонстративный, неуравновешенный,
  дистимный, экзальтированный типы акцентуации.
- «Тест Томаса» — поведение в конфликтных ситуациях (соперничество,
  сотрудничество, компромисс, избегание, приспособление).
- Торонтский алекситимический тест (TAS) — способность различать и описывать
  собственные чувства; фактор риска психосоматики.
- Тест мотивации достижения (ТМД) — стремление к успеху против избегания неудачи
  (формы А/Б по полу).
- Тест мотивационной структуры Ф. Герцберга — гигиенические и мотивационные
  факторы удовлетворённости трудом.
- SCL‑90‑R — выраженность психопатологической симптоматики (9 шкал + 3 обобщённых
  индекса).
- Тест тревожности Спилбергера‑Ханина — реактивная и личностная тревожность.
- Диагностика профессионального выгорания по Н. Е. Водопьяновой — эмоциональное
  истощение, деперсонализация, редукция личных достижений.
- Стилевые особенности саморегуляции поведения (ССП‑98) — планирование,
  моделирование, программирование, оценка результатов, гибкость,
  самостоятельность.
- «Тест Лири» — межличностные отношения: доминирование — подчинение,
  дружелюбие — агрессивность.
- Копинг‑поведение в стрессовых ситуациях — ориентация на задачу, на избегание,
  эмоциональные проявления.
- Смысловые базовые установки (СБУ) — зависимости (вербальная, эмоциональная, от
  достижений), требовательность к себе и другим, ответственность за себя и других.
- Тест жизнестойкости — способность выдерживать стресс без потери
  результативности.
- Тест смысложизненных ориентаций (СЖО).
- Волевые качества личности (ВКЛ) — инициативность, решительность,
  самостоятельность, выдержка, энергичность, внимательность, ответственность,
  настойчивость, целеустремлённость.
- Стратегии совладающего поведения (ССП).
- Опросник Айзенка EPQ — нейротизм, экстраверсия/интроверсия, психотизм.
- Опросник структуры темперамента (ОСТ) В. М. Русалова — 9 шкал предметного и
  коммуникативного аспектов темперамента.
- Опросник профессиональных предпочтений Голланда — 6 типов личности.
- Психологическая оценка организаторских способностей личности.
- Диагностика реализации потребностей в саморазвитии.
- Диагностика лидерских способностей.

### Очередь подключения (предложение)

Критерий — сколько методика даёт для двух вещей сразу: делового решения клиента
и цифрового аватара (FR10, «как подавать»).

1. **Большая пятёрка.** Самый сильный вклад в аватар: самоконтроль —
   импульсивность задаёт объём и форму подачи, эмоциональная устойчивость — тон и
   чувствительность, экстраверсия — темп. Ни одна другая методика из списка не
   даёт столько для «как подавать» за один тест.
2. **«Тест Томаса».** Самый прикладной результат для бизнесмена (переговоры,
   команда, партнёрство) и хорошая пара к Басса‑Дарки: одно и то же поведение в
   конфликте с двух сторон — намерение и форма.
3. **Копинг‑поведение в стрессовых ситуациях** (или ССП‑98, они близки). Как
   человек действует под нагрузкой; напрямую решает, каким должен быть последний
   раздел отчёта — «первый шаг» действием или размышлением.
4. **Торонтский алекситимический тест (TAS).** Прямая проверка того, работает ли
   язык чувств: при высокой алекситимии отчёт, написанный «через переживания», до
   клиента не доходит — это признак `support`/`language` аватара, измеренный, а не
   выведенный косвенно.
5. **Выгорание по Водопьяновой** (либо тест жизнестойкости). Самый частый деловой
   запрос — усталость и падение отдачи; результат короткий и понятный без
   психологической подготовки.

Отдельно: **Герцберг** привлекателен тем, что говорит с бизнесом на его языке
(гигиенические факторы против мотивационных), но заменять им СМУ не нужно —
у СМУ уже отлажена связка с физиологией и разделами отчёта; логичнее добавить
его как второй мотивационный тест.

**SCL‑90‑R и Спилбергер‑Ханин** — клинические инструменты. Технически они не
сложнее прочих, но отчёт по ним для делового клиента легко читается как
медицинский диагноз; подключать их стоит только вместе с отдельным промптом и
решением заказчика о том, кто и как их комментирует.

## Non‑Functional / Constraints

- Диаграмма — детерминированный код (Конституция, принцип I).
- Никаких выдуманных данных (принцип II).
- Чистый PHP без Composer (принцип III).
- Секреты — через ENV / `settings` (принцип IV).
- Шрифт клиентского отчёта — Verdana; бренд — «НейроПро».

## Out of Scope (на эту итерацию)

- Полноценная многопользовательская аутентификация операторов (есть только
  `ADMIN_PASSWORD` для настроек).
- Серверный рендер PDF с встроенным TTF (сейчас — печать из браузера, Verdana
  системная); см. `tasks.md`.
- Биллинг, аналитика использования.

## Acceptance (эталон)

Образец `Sources/Дронов Андрей 19-06-2026 15 02.xls` парсится в:
ФИО «Дронов Андрей», методика «Структура мотивации участия (СМУ)», тип `smu`,
12 баллов `9,9,9,8,9,9,7,7,9,8,9,9`; диаграмма строится; физиология со скриншота
выравнивается по 12 осям; интерпретация генерируется по активному промпту СМУ.

Образец `Sources/Дронов Андрей Басса-Дарки 23-06-2026 13 22.xls` парсится в:
методика «Опросник Басса-Дарки для оценки агрессивности», тип `bd`, 8 баллов
`9,7,7,3,5,8,11,3` (у каждой шкалы свой максимум: 10,9,11,5,8,10,13,9);
индексы считаются математически: агрессивности 27 из 34, враждебности 13 из 18
(оба «выше нормы»); физиология со скриншота выравнивается по 8 осям;
интерпретация — по активному промпту Басса-Дарки.
